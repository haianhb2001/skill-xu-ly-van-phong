# skill-xu-ly-van-phong
Kỹ năng Xử lý Văn phòng triển khai Kiến trúc 2 Chiều giúp AI tự động hóa toàn diện các thao tác tạo lập, chỉnh sửa và chuyển đổi tài liệu văn phòng (Word, Excel, PowerPoint, PDF). Điểm khác biệt cốt lõi là khả năng bóc tách nhận diện thương hiệu (Brand Kit) từ tài liệu mẫu để tái sinh các văn bản mới mang chuẩn mực thiết kế chuyên nghiệp.
